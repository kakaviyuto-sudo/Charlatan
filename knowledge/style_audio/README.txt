YouTube URL → MP3 保存ツール（独立版）
========================================

ファイル:
- youtube_mp3_downloader.py : GUI本体
- setup_and_run.bat         : 必要ライブラリを入れて起動

使い方:
1. この2ファイルを同じフォルダーに置く
2. setup_and_run.bat をダブルクリック
3. 初回は yt-dlp と imageio-ffmpeg をインストール
4. YouTube URLを貼り付け、「MP3に変換して保存」をクリック
5. 保存先:
   C:\Users\kakav\neuro_ai\knowledge\style_audio

仕様:
- 1回に1本ずつ処理
- 保存先の既存MP3も含め最大10件まで
- 既存MP3は自動削除しない
- 同じ動画IDの重複保存を防止
- 再生リスト一括処理は無効
- YouTube側の仕様変更、ログイン・年齢制限・地域制限等で取得できない場合があります

注意:
自分が権利を持つ音声、または権利者の許可があり、ダウンロードが認められているコンテンツに使用してください。
YouTubeの利用規約・著作権・地域の法律を守ってください。
